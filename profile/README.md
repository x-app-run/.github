## What is x-app.run?

A single home for the small utilities you reach for every day — JSON beautifier when an API misbehaves, regex-free duplicate-line remover when a list explodes, an SSL checker before you ship a deploy, a QR generator for a quick handoff. Each tool is one focused page. Open, paste, copy, close.

<table>
<tr>
<td width="33%" valign="top">

### One job per tool
Each utility does exactly one thing well. No tabbed mega-app, no settings rabbit hole. Find the tool, do the task, move on.

</td>
<td width="33%" valign="top">

### Browser-first
Everything that *can* run client-side, does. Your text, your images, your JSON — they don't get shipped to a server when there's no reason to.

</td>
<td width="33%" valign="top">

### Free, ad-supported
No paywall, no signup, no "pro plan." Tools stay open to everyone; ads keep the lights on.

</td>
</tr>
</table>

## Why this organization exists

x-app.run is a closed-source product, so you won't find tool source code in this organization. This space is here to:

- Be the canonical link from any "x-app" reference back to the live site.
- Host issue trackers and feedback channels for the public-facing tools (coming).
- Document any companion utilities, browser extensions, or APIs published under the **x-app-run** name in the future.

If you've found a bug, have a tool idea, or want to report broken behaviour, please reach out via the contact form on [x-app.run](https://x-app.run).
