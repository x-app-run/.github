# x-app-run / .github

This repository hosts the **organization profile README** for [x-app-run](https://github.com/x-app-run) — the GitHub home of [x-app.run](https://x-app.run), a free in-browser collection of 100+ web utilities.

The visible content lives in [`profile/README.md`](profile/README.md). GitHub renders it automatically on the organization's public landing page.

## Layout

```
.github/
├── profile/
│   └── README.md          ← rendered on https://github.com/x-app-run
├── assets/
│   └── x-app-run-logo.svg ← logo referenced by the profile README
└── README.md              ← you are here
```

## Notes

- x-app.run itself is closed-source, so no tool source repositories live in this org yet.
- This repository may grow to host issue trackers, browser extensions, or companion tooling published under the **x-app-run** name.
- For tool feedback or bug reports, use the contact form on [x-app.run](https://x-app.run).
